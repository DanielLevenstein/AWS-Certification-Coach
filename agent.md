# How to Use Coding Agents Effectively

As more developers start integrating agentic tools into their workflows, it becomes increasingly important to ensure these tools are being used effectively.
The most important thing to keep in mind while using coding agents is that AI multiplies human intelligence. We learned in math class that zero times anything is still zero. If you don't put in any human effort for a project, you won't get any usable results.
The other thing to remember is that if the agent can cheat on a task, it will. Agents deleting unit tests or databases have become so common it's become an internet meme.
Below are my tips for how to get coding agents to work for you rather than against you:

1. Audit the codebase before making changes. If an existing method exists for what you are doing, use it.
2. Always write design documents and specifications before writing code.
3. When unit tests fail, add a comment indicating why they failed before changing them.
4. After the feature is complete, review existing markdown files and update documentation if functionality changed.
5. Ensure code is clean enough that a new developer should be able to figure it out quickly.

Review these guidelines with your human agent prior to each release to ensure code quality doesn't degrade over time.
